# FastCast downloads

Public Windows and Android preview downloads. Source code is maintained separately.

## Download

[Download FastCast 0.3.0 Preview 1](https://github.com/antis0007/fastcast-downloads/releases/tag/v0.3.0-preview.1)

[Browse all releases](https://github.com/antis0007/fastcast-downloads/releases)

The release includes a Windows/Android ZIP, a separate Android APK, and SHA-256 checksums.
Extract the ZIP, keep FastCast.exe beside cast-host.exe, and follow its README.txt.

These are the September 6, 2026 preview binaries, not a fresh build. Windows binaries
are unsigned and the APK is debug-signed. LAN or a reachable private mesh is required;
automatic Internet NAT traversal is not implemented. Physical-device playback and
long-session acceptance remain unverified. Read the release notes before installing.
