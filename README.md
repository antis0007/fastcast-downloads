# FastCast public website and downloads

Website: https://antis0007.github.io/fastcast-downloads/

FastCast is a development-preview screen-sharing app for Windows and Android. This repository hosts the static website and public release assets. The native screenshots are dated development-build captures; their captions identify the difference from the downloadable release.

Download Windows and Android builds from the website or [GitHub Releases](https://github.com/antis0007/fastcast-downloads/releases). Use matching versions and a LAN or reachable private network. Consult the release notes for preview limitations.

The website needs no JavaScript or build step. GitHub Pages publishes the repository root. For browser checks, run `npm ci`, `npx playwright install`, and `npm test`. See DESIGN.md for presentation and evidence rules.
