How we write this site.

Say what the binary does

No fake dashboards. No fake user counts. If a test was one LAN run, it says so.

No telemetry here

This website has no analytics, no cookies, no accounts. GitHub still sees downloads. That is GitHub, not us.

Free means free today

No subscription in this preview. That is not a legal promise about every future binary.
