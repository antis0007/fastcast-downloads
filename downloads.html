Before you install

A preview, with
clear expectations.

Windows may display SmartScreen. Android requires permission to install an APK from outside an app store. Confirm the download came from the FastCast release repository before proceeding.

Start on the same LAN or a reachable private network. Sustained playback, audio, remote input, and unrelated-network behaviour still need broader device testing.

macOS, Linux, iPhone, iPad, and browser apps are not available in this release.
