Setup

Two devices.
One invitation.

The device that watches writes the invitation, and the Windows PC that shares imports it. Both need matching builds and a route between them that already works.

1. Install 2. Get an invitation 3. Start sharing Portable & updates

Before you begin

  • Use matching app versions.
  • Start on the same Wi-Fi or LAN.
  • The watching device goes first. It writes the invitation.
  • Keep invitations private.
What runs →
01 / INSTALL

Same build on both ends.

On Windows

  1. Download the Windows installer and open it.
  2. The installer is unsigned. Confirm the file came from this downloads repo.
  3. Finish install and open FastCast.

On Android

  1. Download the Android APK.
  2. If asked, allow install from the browser or file manager.
  3. Open FastCast. You can revoke that install permission afterwards.
02 / CONNECT

Invite comes from the viewer.

The watching device writes it. The sending PC imports it.

Android viewer

Open FastCast and choose Share invite. Hand that string to the sending PC. Not to the internet.

Windows viewer

Receive, then Start receiving, then Copy invitation. Same rule.

Invites can contain connection material. Treat one as access to the session, not as a link to share. Do not paste them in public issues or screenshots.

03 / SHARE

Pick the source. Start.

  1. On the sending PC, open Share and import the invite.
  2. Entire screen or one window.
  3. Computer audio, microphone voice, and remote input are three separate switches. Leave the ones you do not need off — what each one opens.
  4. Start sharing. Look at the actual viewer, not only the sender UI.
  5. Stop sharing when you are done.

Nothing connects? Connection checklist.

OTHER INSTALL OPTIONS

Zip and USB.

Portable bundle

Extract first. Keep FastCast.exe next to cast-host.exe. Install FastCast.cmd if you want the installed copy.

USB updates for Android

The zip has the matching APK and Update connected devices.cmd for phones that already have USB debugging authorized.

Updating

Stop sessions. Install a matching Windows + Android pair. Keep the old zip if you need to go back.
