Getting started

Your first
shared screen.

You’ll need a Windows PC to share from, a Windows or Android device to watch on, and a network route between them.

1. Install2. Get an invitation3. Start sharingPortable & updates

Before you begin

  • Use matching app versions.
  • Start on the same Wi-Fi or LAN.
  • Keep invitations private.
Check requirements →
01 / INSTALL

Put FastCast on both devices.

On Windows

  1. Download the Windows installer and open it.
  2. Review the publisher warning for this unsigned preview. Confirm the file came from the official FastCast downloads repository.
  3. Finish installation and open FastCast.

On Android

  1. Download the Android APK on your phone or tablet.
  2. Open the APK. If prompted, grant your browser or file manager permission to install it.
  3. Complete the system installation and open FastCast. You can turn that install permission off afterwards.
02 / CONNECT

Get an invitation from the viewer.

The viewing device creates the invitation. The sharing PC imports it.

Android viewer

Open FastCast and choose Share invite. Transfer the invitation privately to the sharing PC.

Windows viewer

Choose Receive, then Start receiving and Copy invitation. Transfer it to the sharing PC.

Invitations can contain connection and access information. Don’t post them in public issues, chats, or screenshots.

03 / SHARE

Choose the source. Start the session.

  1. On the sending PC, open Share and import the receiving device’s invitation.
  2. Select the entire screen or the window you want to share.
  3. Review audio and remote-input settings. Enable only what you want for this session.
  4. Choose Start sharing. Check the picture and any enabled sound on the actual viewing device.
  5. Use Stop sharing when finished.

Connection trouble? Start with the connection checklist.

OTHER INSTALL OPTIONS

Portable use and manual updates.

Portable bundle

Extract the ZIP first. Keep FastCast.exe next to cast-host.exe. Use Install FastCast.cmd if you want to install from the bundle.

USB updates for Android

The bundle includes the matching APK and Update connected devices.cmd for devices with USB debugging already enabled and authorized.

Updating this preview

Download a matching Windows and Android release, stop active sessions, and install the new pair. Keep older packages if you need to return to a previous preview. Read the release notes before switching versions.
