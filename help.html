The basics

Is FastCast free? Are there subscriptions?

Yes. The current public preview is free to download and use, with no subscriptions or billing sign-up. This applies to the current offer; it is not a lifetime pricing promise for future services.

Can I replace Discord or Microsoft Teams with it today?

Not yet. FastCast’s current public preview is a screen-sharing app. It does not provide the full messaging, meeting, or hosted community experience of those products. Smaller-group communication is the project’s direction.

Can I use FastCast in a web browser, on a Mac, or on an iPhone?

The current downloads are for Windows and Android. macOS, Linux, iOS, and browser clients are unavailable. See the platform table.

Are the screenshots the same as the download?

The site shows the native Windows development interface captured September 7, 2026 in the Phosphor theme. Controls can vary by configuration and version. The captions identify the development build; the images are not simulated sessions.

Installation & updates

Why does Windows show a publisher or SmartScreen warning?

The preview installer is unsigned. Confirm its name and source against the official release, and use the published checksums if you want to verify the file. Do not disable system protection globally.

Why won’t Android install the APK?

Android may ask for permission to install from your browser or file manager. A signing-key mismatch with an existing installation can also prevent an update. Record the exact system error and app versions before reporting it; uninstalling can remove app data.

Which files should I use from the ZIP?

Extract the archive. Keep FastCast.exe and cast-host.exe together for portable Windows use, or run Install FastCast.cmd. The APK in the same bundle is the matching Android viewer.

How do I update the current preview?

Use the release page to get matching Windows and Android packages. Stop active sessions before installing. Do not assume a newer development screenshot means a newer public package is available.

Connection & sharing

The devices won’t connect. What should I check first?
  1. Confirm both apps came from the same release.
  2. Put both devices on the same LAN, avoiding isolated guest Wi-Fi.
  3. Start receiving on the viewing device and create a fresh invitation.
  4. Import that invitation on the sharing PC.
  5. Review the specific firewall prompt or connection error. Allow only the required app on a trusted network.

If it still fails, report the exact error without the invitation itself.

Can I connect across the internet?

The public preview needs a reachable private-network route for devices on different networks. It does not include automatic public internet traversal or a managed relay. Test on the same LAN first to separate app setup from network reachability.

Where does the invitation come from?

The viewing device creates it. On Android, choose Share invite. On a viewing PC, choose Receive, Start receiving, then Copy invitation. The sending PC imports it. Follow the invitation steps.

Audio, input & performance

I can see the picture but can’t hear sound.

Check that the intended audio option is enabled on the sending PC, that the viewer volume and output device are correct, and that any required microphone permission is granted. Audio behaviour is still under preview testing and varies by device.

Why doesn’t remote input work?

Remote input needs its own session setting and the required device permissions. Check those before testing a specific key, pointer, or gesture. Report the sending and viewing platforms along with the input that failed.

What frame rate or latency is guaranteed?

No performance guarantee is published for this preview. Hardware, source content, encoding settings, decoding, and the network affect the result. The website does not use illustrative graphs as benchmark evidence.
