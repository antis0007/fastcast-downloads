GET CONNECTED

A clear path
from here to there.

Start with both devices on the same Wi-Fi or LAN. For different networks, you need an existing reachable private-network route.

  1. 01

    Install the matching apps.

    Run the Windows installer on your PC. Install the APK on Android, or the Windows app on a second PC.

  2. 02

    Get an invitation from the viewer.

    On Android, choose Share invite. On a viewing PC, choose Receive → Start receiving → Copy invitation.

  3. 03

    Choose your source and share.

    Import the invitation on the sending PC. Select a screen or window, then choose Start sharing. Enable audio or input as needed.

Using the portable bundle or USB updates?

Extract the ZIP before opening it. Run Install FastCast.cmd to install, or keep FastCast.exe beside cast-host.exe for portable use. The bundle includes the matching APK and Update connected devices.cmd for authorized USB-debugging devices.

Windows hardware

NVIDIA NVENC is preferred for sending. CPU H.264 fallback is available on other supported PCs. Windows receiving needs the Windows media components.

Network reachability

Use a LAN or reachable private network. Automatic public internet traversal and a managed media relay are not available.

Preview boundaries

Voice and remote input depend on the device and granted permissions. Preview availability does not mean every hardware combination is verified.

Formula and what’s excluded

Decimal GB = Mbps × 60 × minutes ÷ 8,000. Assumes a constant video bitrate and one viewer. Excludes audio, protocol overhead, retransmissions, and coordination traffic. An external private mesh may relay your traffic; this calculator does not estimate cloud costs.
