Connections

Direct when devices
reach each other

Your screen goes straight to the other device whenever the two can reach each other. If they can't, the encrypted picture takes the relay instead.

Your PC encodes the picture; the watching device decodes it. Nobody in between can read it.

Pairing and discovery messages help the two devices find each other. They travel separately from the screen and audio.

Start on your own network.

We tested earlier builds on a local network and have not yet confirmed playback on real hardware for this one. On networks that block UDP outright there is no media fallback.

Help

Getting started

Use the same version on both devices. If they cannot connect, check whether your network allows devices to communicate with each other.

The devices won't connect.

Check that both are on the same version. Guest Wi-Fi often isolates devices even when the network name matches, so try another network. Then make a fresh invitation on the watching device and import it again. Connection checklist.

Is this remote control, or watching?

Watching, unless you turn remote input on. That switch is experimental and we have not measured whether it keeps up for games.

What do I need before installing?

A Windows x64 PC to send, and a second Windows PC or an Android 8+ device to watch. The Windows installer is unsigned and the APK is debug-signed, so compare the published checksum before you run either. Install notes.
