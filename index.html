Under the surface

The direct road
comes first.

Media travels straight between the two devices. When that path is open, nothing sits in the middle of it.

The Windows PC encodes the screen. The device that watches decodes it. A reachable route keeps the media between two machines you already own.

A relay is the fallback when the road is blocked. This preview ships without one.

What the public build actually needs.

0.3.2 Preview 2 wants a reachable LAN or private-network route. Automatic internet traversal and a FastCast-managed relay are not in the package. Network requirements.

When it fails

Start with
the basics.

Checks worth making before you change every setting or blame the router.

The devices won't connect.

Matching versions on both devices, and a network they can both reach — guest Wi-Fi can isolate them even when the name matches. Make a fresh invitation on the viewer and import it on the sharing PC. Connection checklist.

Is this remote control, or watching?

Watching is the point. Remote input is a separate, experimental permission — not a promise of responsive control in every game. Leave it off and the view still works.

What do I need before installing?

Windows x64 to send, and a second Windows PC or Android 8+ to watch. The Windows installer is unsigned and the APK is debug-signed, so check the published checksum. Install notes.
