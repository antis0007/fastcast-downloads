Hypothetical relay egress for comparison. FastCast does not currently provide a managed media relay. An external private mesh may use its own relay.

How this estimate works

Decimal GB = Mbps × 60 × minutes ÷ 8,000. Assumes a constant video bitrate and one viewer. Excludes audio, protocol overhead, retransmissions, and coordination traffic. The direct-route bar counts media server egress only; your devices still transfer the video. These are calculations, not measured performance or a cloud bill.

SETUP

Install and connect

Use matching apps on a shared LAN or an existing reachable private network. Windows prefers NVIDIA NVENC and uses CPU H.264 on other supported PCs.

  1. 01

    Download the bundle

    Get the Windows app and matching Android APK from the same preview release. Check the signing notes and requirements before installing.

  2. 02

    Install both sides

    Extract the ZIP and run Install FastCast.cmd on Windows. Open the APK on Android, or use Update connected devices.cmd from the bundle over USB.

  3. 03

    Import an invitation

    On Android, select Share invite. Import it on the PC, choose a screen or window, then select Start sharing.
