Sending PC

Windows hardware

NVIDIA NVENC is preferred for sending. A CPU H.264 fallback is available on other supported PCs. Actual performance depends on your hardware and chosen settings.

Viewing PC

Media components

Windows receiving needs the Windows media components. Some Windows editions may need those components installed separately.

Phone or tablet

Android receiver

Install the matching APK on Android 8 or newer. Decoder, audio, and remote-input support can vary by device.

The connection between them

Start local.
Check the route.

Use the same LAN or a reachable private network. Guest Wi-Fi and client isolation can prevent devices from reaching each other even when the network name looks the same.

The public preview does not include automatic public internet traversal or a managed media relay. A private network route needs to exist before FastCast can use it.
