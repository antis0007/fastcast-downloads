This website

The FastCast website is a static site hosted on GitHub Pages. Its code includes no analytics, advertising scripts, tracking pixels, account system, or billing forms. Fonts and site images are hosted with the website.

The help search runs in your browser. Search terms are not sent to FastCast. The site’s own JavaScript does not set cookies or save browser storage.

GitHub hosting, downloads, and feedback

GitHub serves this site and the release downloads. Visiting those services can involve request logging under GitHub’s privacy statement.

Feedback links lead to public GitHub issues. Anything you post there is public, and posting requires a GitHub account. Avoid sharing personal information or private session details.

Screen content and invitations

An entire-screen share can include notifications and personal information. Choose a specific window where appropriate and review what is visible before starting.

Treat invitations and recovery codes as private. Do not attach them to bug reports or leave them visible in screenshots. Enable microphone, audio, and remote input only when intended for the session.

Automatic network discovery

When a receiver is waiting for a connection, it automatically contacts FastCast's own STUN service, falling back to Cloudflare's and Twilio's public STUN services, to discover a reachable address, and asks your router (via UPnP, NAT-PMP, or PCP) to open a temporary port mapping. These requests happen every time the receiver starts. This public preview has no setting to turn them off.

The STUN providers see the receiver's public IP address and the fact that a STUN request was made; they do not see screen content, audio, or account information. If a session cannot reach its peer directly, the FastCast relay forwards that session's media and therefore carries it. Your router sees the local mapping request. Router leases expire on their own (around two hours) and are renewed only while the receiver is active.

App privacy and security scope

This page describes the website and practical sharing precautions. It is not a security audit of the native app, a claim of universal end-to-end privacy, or a guarantee about every device and network.

For the current package’s implementation and testing boundaries, read the release notes. If you report a suspected security issue in the public tracker, start with a minimal description and omit credentials, private data, and exploit details.
