CURRENT PREVIEW

September 10, 2026

FastCast 0.3.2 Preview 2

UX sheets, host-first Go live watch-place, rustls call-listen fix. Android still viewer-only for capture. Matching Win+Android preview packages.

In these files

  • Windows sending and receiving, plus Android receiving.
  • Session invitations and screen or window selection.
  • Audio and remote-control controls exist in the UI. Physical remote input is unproven. Audible output was not independently confirmed.
  • Matching bundle and USB update helpers.

Holes

  • Windows binaries are unsigned; Android is debug-signed.
  • A reachable peer route such as a LAN or private mesh is required.
  • Automatic universal Internet traversal is not available.
  • A FastCast-managed media relay is not available.
  • Android is a viewer in this public release, not a sender.
  • macOS, iPhone, iPad, and browser apps are not available.
  • Linux is not in this public zip. Source has a viewer; Linux send is not a product.

SHA-256 checked on the published files. That is not the same as “every phone, every NAT.”
