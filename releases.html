CURRENT PREVIEW

September 7, 2026

FastCast 0.3.1 Preview 1

Matching Windows and Android preview packages, with a Windows installer, Android APK, and portable bundle.

In this release

  • Windows sending and receiving, plus Android receiving.
  • Session invitations and screen or window selection.
  • Audio and remote-control options in the current preview implementation.
  • Matching bundle and USB update helpers.

Known boundaries

Windows binaries are unsigned; Android is debug-signed. Use a LAN or reachable private network. Sustained visible playback, audible sound, input combinations, and unrelated-network regression testing remain incomplete. Automatic public traversal and managed media relay are unavailable.

Published packages were checked for SHA-256 integrity and matching bundled components. Package checks are separate from device and network qualification.
