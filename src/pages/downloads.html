Installation and signing

The Windows installer is unsigned and may trigger a SmartScreen warning. Compare the exact filename and checksum with this release before deciding to proceed. Keep operating-system protections enabled.

Android may ask to allow installation from the browser or file manager you used. That permission is specific to the installing app and can be revoked afterward. This APK is debug-signed and receives a shared screen.

Then try matching versions on a LAN you control. Platform requirements cover hardware, and the capability list separates included features from test evidence.
