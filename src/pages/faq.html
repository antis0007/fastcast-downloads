Getting started

Is Pyrenet free?

The public preview packages are free, with no subscription and no account required for screen sharing. Friends, calls, rooms, and files use a device-owned account that never uploads a contact list to a cloud server.

Can I replace Discord or Teams with Pyrenet today?

No. The preview adds voice, chat, and file transfer, but without history, moderation, or public room links. It is built for people who already know each other, not for open communities.

What platforms are supported?

Windows x64 sends and watches. Android 8+ watches. A Linux viewer exists in source only. macOS, iOS, and browsers are not available. Full platform table.

How do I update from an older preview?

Stop any active session, then install the matching Windows and Android packages over the old install. Do not assume a newer screenshot means a new public package is ready.

Installation

Windows shows a SmartScreen warning.

The preview installer is unsigned. Compare the filename and SHA-256 checksum against this release before proceeding. Do not disable SmartScreen globally.

Android blocks the APK install.

Android may ask for permission to install from your browser or file manager. A signing-key mismatch with an existing install can also block updates. Record the exact error before uninstalling.

Do I need the same version on both devices?

Yes. Mismatched builds are the most common failure. The invitation flow will not complete if the versions differ.

Connections

The devices won’t connect.

Check four things, in order: same release, same LAN, no isolated guest Wi-Fi, and a freshly created invitation. Full connection checklist.

Can I share over the internet?

Direct routes work on any reachable network. Unrelated-network playback is not yet qualified, and networks that block UDP have no media fallback. A relay fallback exists but is not a managed service.

What does the relay do?

When two devices cannot reach each other directly, Cast forwards encrypted media through a relay node. The relay reads no payload and keeps no state.
