01 / INSTALL

Install {{PRODUCT}} on both devices

Use the matching versions from the downloads page. You need a Windows PC to share; the device watching can be another Windows PC or an Android device.

On Windows

  1. Download the Windows installer.
  2. The installer is unsigned, so check that you downloaded it from the {{PRODUCT}} release linked on our downloads page before running it.
  3. Complete the installation and open {{PRODUCT}}.

On Android

  1. Download the Android APK.
  2. If Android asks, allow your browser or file manager to install the APK.
  3. Open {{PRODUCT}} after installation. You can then revoke the browser or file manager's permission to install apps.
02 / CONNECT

Create an invitation on the watching device

Follow the instructions for your viewer below, then send its invitation privately to the person at the sharing Windows PC.

Android viewer

Open {{PRODUCT}} and choose Share invite to send the invitation to the sharing PC.

Windows viewer

Choose Receive, then Start receiving, then Copy invitation. Send the invitation privately to the sharing PC.

An invitation contains connection material that can grant access to the session. Keep it between the participants and remove it from screenshots or public bug reports.

03 / SHARE

Start sharing from the Windows PC

  1. On the sending PC, open Share and import the invite.
  2. Select the entire screen or one window as the capture source.
  3. Choose whether to include computer audio, microphone voice, or remote input. Each has a separate switch; enable only what the session needs. Read about these permissions.
  4. Select Start sharing and check that the picture appears on the watching device. If you enabled audio, check that it can be heard there too.
  5. Select Stop sharing when you are finished.

If the devices do not connect, work through the connection checklist to check versions, invitations, and network access.

04 / TOGETHER

Talk, write, and send a file

Once the picture is working between two devices, the rest of the session is available from the same connection.

  1. Start a voice call with an accepted friend. A call and a screen share run at the same time; the share still only begins when you start it.
  2. Open a room to keep a written conversation beside the session. Rooms outlive a single call, but they are not a durable archive.
  3. Send a file when you need to hand something over. The other side accepts it explicitly, and the transfer needs a direct route — there is no relay fallback for files.
  4. On Windows, add more screens to a Table: up to four live friend screens at once, each admitted separately.

All of this is preview work with real gaps — no message reactions, editing or deleting, and no unread counts. What calls and rooms do today.

OTHER INSTALL OPTIONS

Portable installs and updates

Portable bundle

Extract the downloaded ZIP into a folder before running {{PRODUCT}}, and keep FastCast.exe and cast-host.exe together. To install a copy from the bundle, run Install {{PRODUCT}}.cmd.

USB updates for Android

The ZIP includes the matching Android APK and Update connected devices.cmd. You can use that script to update a connected phone if USB debugging is already authorized; otherwise, install the APK using the Android steps above.

Updating

Stop any active sessions before updating, then install matching versions on both devices. Keep the previous portable bundle if you may need to return to that version.
