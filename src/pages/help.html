The basics

Is {{PRODUCT}} free? Are there subscriptions?

The current Windows and Android packages are free, with no subscription. Screen sharing does not require an account; friends and calls use a device-owned account.

Can I replace Discord or Microsoft Teams with it today?

No. The preview does have voice calls, room discussions and file transfer alongside screen sharing, but they are preview features for people who already know each other — not hosted communities with moderation, searchable history, or an invite link anyone can open. Installation & updates

Why does Windows show a publisher or SmartScreen warning?

The preview installer is unsigned. Confirm its name and source against the official release, and use the published checksums if you want to verify the file. Do not disable system protection globally.

Why won’t Android install the APK?

Android may ask for permission to install from your browser or file manager. A signing-key mismatch with an existing installation can also prevent an update. Record the exact system error and app versions before reporting it; uninstalling can remove app data.

Which files should I use from the ZIP?

Extract the archive. Keep Cast.exe and cast-host.exe together for portable Windows use, or run Install {{PRODUCT}}.cmd. The APK in the same bundle is the matching Android viewer.

How do I update the current preview?

Use the release page to get matching Windows and Android packages. Stop active sessions before installing. Do not assume a newer development screenshot means a newer public package is available.

Connection & diagnostics

The devices won’t connect. What should I check first?
  1. Confirm both apps came from the same release.
  2. Put both devices on the same LAN, avoiding isolated guest Wi-Fi.
  3. Start receiving on the viewing device and create a fresh invitation.
  4. Import that invitation on the sharing PC.
  5. Review the specific firewall prompt or connection error. Allow only the required app on a trusted network.

If it still fails, report the exact error without the invitation itself.

Can I connect across the internet?

The app tries direct connections first, using address discovery and pairing, with a {{PRODUCT}} relay fallback when available. Unrelated-network playback remains unqualified: these paths do not guarantee a connection through every router or firewall. Networks that block UDP have no media fallback in this preview.

Test on the same LAN first to separate app setup from network reachability. An existing private mesh or VPN can provide another reachable route, subject to its own policies. Compare direct and relayed paths, or read how discovery and pairing work.

Where does the invitation come from?

The viewing device creates it. On Android, choose Share invite. On a viewing PC, choose Receive, Start receiving, then Copy invitation. The sending PC imports it. Follow the invitation steps.

Audio, input & performance

I can see the picture but can’t hear sound.

Check that the intended audio option is enabled on the sending PC, that the viewer volume and output device are correct, and that any required microphone permission is granted. Audio behaviour is still under preview testing and varies by device.

Why doesn’t remote input work?

Remote input needs its own session setting and the required device permissions. Check those before testing a specific key, pointer, or gesture. Report the sending and viewing platforms along with the input that failed.

What frame rate or latency is guaranteed?

This preview does not guarantee a frame rate or latency. Results depend on hardware, encoding settings, decoding support, and the network. Android uses a hardware decoder when the device has one; Linux source builds can use VA-API when those plugins exist. The bandwidth calculator estimates traffic; it does not measure playback performance.

Calls, rooms & files

Can we talk while sharing a screen?

Yes. A voice call and a screen share run at the same time over the same encrypted route, and the share starts only when you explicitly start it. Voice is preview: microphone behaviour, echo, and moving between networks mid-call are untested on real hardware.

How many people can watch one screen?

A Windows capture serves up to eight separately admitted viewers, and a Windows Table shows as many as four live friend screens at once. Every viewer is admitted by invitation; there is no open link. More about Tables.

Is the text chat saved anywhere?

No. Room discussions run through the coordination service and are not a durable archive held for a device that is switched off. Do not rely on this preview to keep a conversation for you.

Why can I not react to, edit, or delete a message?

Those operations do not exist in the coordination service yet, so the app does not show controls that would do nothing.

A file transfer will not start.

File transfer needs a direct route between the two devices and explicit acceptance on the receiving side. There is no relay fallback for files, so on a network where only a relayed route works the transfer will not begin.
