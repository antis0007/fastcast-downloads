Your first shared screen

Two devices.
One invitation.

The watching device goes first. It creates the invitation for the Windows PC that will share. Start with matching versions on the same network.

Start hereI'm watching a screen↗ ThenI'm sharing my screen↗

  1. Create an invitation.

    Open Receive on the viewing device. Send its invitation privately to the person sharing.

  2. Choose what to share.

    On the Windows PC, open Share and import the invitation. Pick a screen or window, then review audio and input permissions.

  3. Bring the picture across.

    Select Start sharing and check the picture on the viewer. Use Stop sharing on the PC when you're finished.

Audio and control in this preview

Computer audio decoded in the recorded LAN test; audible playback remains unconfirmed. Microphone, physical echo behavior and Android remote input remain unqualified.

comes first.

Before you begin

A few useful
answers.

Device support, invitations and permissions. The practical details for your first session.

The devices won't connect.

Matching versions on both devices, and a network they can both reach — guest Wi-Fi can isolate them even when the name matches. Make a fresh invitation on the viewer and import it on the sharing PC. Connection checklist.

Is this remote control, or watching?

Watching is the point. Remote input is a separate, experimental permission — not a promise of responsive control in every game. Leave it off and the view still works.

What do I need before installing?

Windows x64 to send, and a second Windows PC or Android 8+ to watch. The Windows installer is unsigned and the APK is debug-signed, so check the published checksum. Install notes.

Do I need an account?

Sharing a screen needs no account. Friends and calls use a device-owned account. The current development preview has no subscription charge.

Will it work across the internet?

FastCast tries direct routes and has a relay fallback, but unrelated-network media remains unqualified. Networks that block UDP have no media fallback in this release. Explore the connection paths.
