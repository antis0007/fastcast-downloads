Report a bug

Found a crash, a decoding artefact, a mismatch between docs and behaviour, or a window that should not have shared? File it against the main app repository.

Include the version tag, both device models, and the exact error. Remove invitations and private data before attaching logs.

What we value

Honest limits. Every capability has a status word. If something is not tested yet, we say so plainly. A control that does nothing is worse than no control.

Small surface area. Fewer dependencies, fewer telemetry channels, fewer places for a bug to hide.

Civil discussion. Feature requests are fine; demands, insults, and threats are not. The issue tracker is a shared workspace, not a battlefield.

Good first issues

These tasks have well-defined scope and no hidden dependencies.

Documentation

Clarify any paragraph that takes more than one read. Add labelled screenshots to setup steps that only describe clicks.

Testing

Reproduce a bug on a second device, capture a log, or confirm a fix on a fresh install.

Accessibility

Check contrast ratios, keyboard flows, and screen-reader announcements. Report the exact axis and OS.
