Sending PC

Windows encoding

NVIDIA NVENC is the validated path. Other supported PCs fall back to the built-in Windows CPU encoder, which costs processor time. Results depend on your hardware and the settings you pick.

Viewing PC

Windows playback

Windows receiving uses the Windows media components. Some editions may need those components installed separately before playback works.

Phone or tablet

Android playback

Install the matching APK on Android 8 or newer. Decoder and audio behaviour varies by device, and remote input from Android is not yet proven.

Network
requirements.

Use the same LAN or a reachable private network. Guest Wi-Fi and client isolation can prevent devices from reaching each other even when the network name looks the same.

Linux viewer setup

Use Ubuntu 24.04 x64 or a compatible Linux desktop with ALSA and GStreamer 1.22 or newer (core, app and video libraries). Extract the archive, open its folder in a terminal and run ./fastcast. Optional VA-API or NVIDIA GStreamer decoder plugins enable hardware decoding where supported; otherwise it uses OpenH264.

This package does not include Linux screen broadcasting. The hosted room-voice update does not add Linux calling. Physical playback and audible output remain unqualified.
