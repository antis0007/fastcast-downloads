Every capability, and its real status

The whole feature list.

A capability is called available only where it is implemented and has been exercised on hardware. Anything still waiting on physical validation says so here rather than in a footnote.

FastCast {{RELEASE_LABEL}} capabilities and their current status
CapabilityStatusWhat that means today
Screen and window captureAvailableShare an entire screen, or pick a single window, from a Windows x64 PC.
Video quality controlsAvailableChoose 60 or 30 fps and adjust stream quality while a session is running.
H.264 encodingAvailableNVIDIA NVENC is the validated path. Intel and AMD PCs fall back automatically to the built-in Windows CPU encoder, which costs processor time. Vendor hardware acceleration and physical Intel/AMD streaming tests are still pending.
Android receivingAvailableAndroid 8 or newer, decoding in hardware. Validated on one device.
Windows receivingAvailableA second Windows PC can receive the screen and system audio. Both ends need matching builds.
Private session admissionAvailableThe receiving device issues a private invitation that authorises the session over a pinned QUIC connection. Expiry, replay and revocation pass loopback tests; physical regression testing is still open.
Computer audioAvailableThe sending PC’s audio travels with the screen. A fresh audible regression run on a phone is still outstanding.
Two-way microphone voicePreviewBuilds and passes its checks. Physical round-trip and echo testing have not been done.
Remote control from AndroidPreviewBuilds and passes its checks. Physical input, and behaviour inside native games, are unproven.
Cursor appearance and effectsPreviewDesktop cursor styling with a local effects budget. The current build labels this preview only.
Viewing outside your local networkLimitedWorks across a private mesh you already run. STUN probing is implemented, but automatic traversal is not, so a reachable route has to exist first.
Device-owned accounts and contactsLimitedHeld locally on Windows. Sync, recovery, and global handle claims are not implemented.
Automatic update checksUnreleasedPresent in development builds, not in this download. Update by installing a newer package over the old one.
Managed relay and multi-viewer roomsNot yetThere is no FastCast-run media relay, and multi-viewer rooms are not implemented.
macOS, Linux, iPhone and iPadNot yetNot implemented. Windows x64 and Android 8 or newer only.
