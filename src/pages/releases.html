WINDOWS + ANDROID

{{PUBLISHED}}

{{RELEASE_LABEL}} video recovery and controller setup

Update both Windows PCs and Android receivers. The Windows installer and portable bundle include the controller driver, so no separate driver download is needed. Windows asks for administrator approval when controller support is missing; an existing shared driver stays installed.

  • Video recovery tracks picture progress independently of audio. A decoder that stops producing pictures is recreated for the next repair keyframe.
  • Static-picture keepalives confirm only the frame actually decoded. The earlier fullscreen, remote-play controls and keyframe delivery fixes remain included.
  • Windows and both Android native libraries are built from the same committed source, with package checksums verified before the download links change.

This is a development preview. Compilation and package verification do not establish physical playback, WAN recovery or controller installation acceptance. No automated tests or hosted build CI were run. Community content sync requires a separate server upgrade that this release does not deploy.

WINDOWS UPDATE

October 3, 2026

Preview 7 PC fullscreen patch

The Preview 7 Windows installer and portable ZIP named PC-Fullscreen include this patch. Install it manually on both Windows PCs, including PCs already running Preview 7. The app still reports Preview 7; choose the files with PC-Fullscreen in their names. The ZIP includes the released Preview 7 Android APK.

  • Fullscreen uses the complete window for video. A temporary overlay gives access to controls without reducing the picture.
  • Controls hide during remote input. Ctrl+Alt+Shift+Space releases input and opens controls; Ctrl+Alt+Shift+Backspace releases input and exits fullscreen. While watching, the top edge reveals controls.
  • Take control, mute and fullscreen remain directly accessible. More contains input devices, audio levels, view options, connection details and disconnect.
  • Enabling remote input selects immediate Gaming playback. A direct 1080p60 / 20 Mbps preset is available on the sharing PC. Connection details show the negotiated video buffer and slow decode work.
  • Older retry keyframes cannot reset a healthy decoder that has advanced past them. Reliable bootstrap frames also count in complete-frame observations.

Local compilation, native fullscreen layout captures and architecture validation cover this patch. Live stream quality, gameplay latency and recovery under network loss still require physical-device verification.

WINDOWS + ANDROID

October 3, 2026

Preview 7 streaming and receiver controls

The Windows download, Android APK and portable bundle contain the combined streaming and controls changes. Update both Windows PCs and Android receivers. The APK retains the earlier signing certificate and uses version code 22, so it can upgrade the installed preview.

  • Android restores permitted control access, exposes a mouse/keyboard or gamepad shortcut, and offers immersive Fit/Fill height with bounded panning.
  • A smaller Android live panel hides after inactivity. Tap video to restore it; screen reader timing, keyboard focus and ongoing gestures keep controls accessible. Narrow screens can scroll the view controls.
  • Windows keeps the compact viewer, explicit local controller selection, independent audio levels and input release shortcut.
  • Supported NVIDIA hardware retains NVENC for scaled captures. The receiver keeps buffer reuse and the previously measured conversion changes.
  • Intentional buffering is separated from decoder pressure. Repair frames have a bounded delivery window, stale losses preserve the repaired chain, and input or one viewer failing does not stop independent video.
  • Buffered PC playback begins decoding before display time; Gaming playback remains immediate. Actual bitrate still adapts to the connection.

Optimized Windows builds, Android release builds/lint, architecture and package checks passed locally. Both packaged Android libraries match rebuilt source after stripping. Physical Android and sustained two-PC/GPD gameplay, motion quality and input-to-photon latency remain unverified. No automated tests or hosted CI ran for this update.

Update both Windows PCs. Before starting the share, the gaming PC must enable the intended viewer's input permissions and have a virtual Xbox controller driver installed. On the handheld, select the connected controller, center the sticks and release buttons, then use Take control.

The Linux download remains the separately published Preview 6 viewer.
