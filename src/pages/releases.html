This is a planning snapshot, not a release announcement. The 0.4.0 Preview 1 downloads below remain the current packages. Scope, version number, date and package contents will be set after the app changes are integrated and pass stability checks.

Candidate improvements being integrated

  • A more consistent desktop experience, with clearer typography, theme and density choices, and a more complete conversation interface.
  • Voice that fits more naturally alongside calls, room conversations and screen sharing.
  • Safer share start, stop, retry and recovery behavior as connections change.
  • Reaction controls in the app. The coordination service supports reactions; the current public app does not yet expose them.

Release gates

  • Integrate and review the active feature branches without including unrelated or unfinished work.
  • Run the focused Windows and Android checks, then verify sharing, receiving, voice and conversation flows on real devices and networks.
  • Choose the version and publish matching packages only after those checks pass.
