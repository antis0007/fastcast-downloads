WINDOWS UPDATE

October 3, 2026

Preview 6 Windows capture and viewer update

The Windows download and combined Windows/Android bundle now include the updated Windows app. Android and Linux retain their existing Preview 6 packages. This update is a portable ZIP; close the old app, extract into a new folder and run Start Pyrenet.cmd.

  • Windows 10 capture uses the border setting supported by the operating system.
  • Incoming screen sessions open the viewer, and valid late decoded frames remain available for display.
  • Compact viewer controls, centered video, clear waiting/recovery states and fullscreen without the app shell.
  • Explicit local Xbox controller selection, separate computer/voice audio levels, and Ctrl+Alt+Shift+Backspace to release remote input.

Local checks, the optimized Windows build and native offline layout review passed. Two-PC/GPD playback, 1440p quality and Ace Combat/controller gameplay remain unverified.
