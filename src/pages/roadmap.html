Candidate work

Preview 2 and next steps

Preview 2 ships desktop improvements and a Linux viewer. Physical-device acceptance and deployment of room voice channels remain separate next steps.

01

A clearer desktop and conversation experience

The desktop preview includes a consistent visual system, text and density choices, local message times, 12/24-hour controls, adjustable chat text size and reduced motion. Search covers loaded messages in the selected conversation; cross-group indexing and media/tag filters remain planned.

02

Voice across calls and shared spaces

Existing calls remain preview. Room voice channels are unavailable on the hosted service until compatibility and deployment checks pass.

03

More reliable sharing and recovery

Preview 2 includes tested lifecycle changes for cancellation, retry and reconnect. Physical sharing, audible media and unrelated-network acceptance remain pending.

Preview 2 is a qualified development release. Local tests and package verification do not establish physical-device or network reliability.

Network discovery controls

Receivers can now turn off STUN lookups, router mapping, or both, and a machine-wide override can force that choice for headless use. A smaller-group direction

Longer-term development

Small groups are no longer only a plan. Voice calls, Tables holding several live screens, room discussions and consent-based file transfer all exist in preview, and that page states what each one still cannot do. None of them is presented as a supported workflow, because none has passed physical acceptance across unrelated machines.

Reaction controls exist in the published desktop source; physical-device acceptance remains open. Message editing, deletion and unread counts remain unavailable. Recoverable devices and synchronized watching of a local file remain longer-term plans. Matching Windows, Android and Linux viewer downloads are available. Linux screen broadcasting is not included. Packages for macOS, iPhone and iPad, and Android screen broadcasting, remain unavailable.

Website comparison tables will stay “Not measured” until a public evidence index exists. Help shape the sequence through the issue tracker, without posting invitations or private screen content.
