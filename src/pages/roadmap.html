TESTING LIMITS

Connection and playback limits

Direct routes and a {{PRODUCT}} relay fallback are implemented. This is not a Discord or Teams replacement, and there is no guarantee of 60 fps, freeze-free playback, or automatic connections across the public internet. A ten-minute Windows-to-S25 run passed controlled outage recovery. Longer sessions, audible media and unrelated-network playback still need validation.

{{RELEASE_LABEL}} and next steps

{{RELEASE_LABEL}} improves constrained-link playback, Android viewing and group sender authentication. Windows-to-S25 playback and generated-audio group recovery were checked; wider device coverage, audible calls and measured end-to-end latency remain next steps.

01

A clearer desktop and conversation experience

The desktop preview includes a consistent visual system, text and density choices, local message times, 12/24-hour controls, adjustable chat text size and reduced motion. Search covers loaded messages in the selected conversation; cross-group indexing and media/tag filters remain planned.

02

Voice across calls and shared spaces

Existing calls remain preview. Hosted coordination supports Windows room voice channels after migration and rollback checks. A three-participant phone/desktop generated-audio probe passed. Audible microphone and speaker quality still need acceptance testing.

03

More reliable sharing and recovery

Video packets are paced, CPU refresh frames occur on demand, and Android recovers its decoder reference after loss. A five-minute 720p run rendered all 8,990 frames at 29.96 fps over a controlled 5 Mbps path. Capture timing still varies.

{{RELEASE_LABEL}} remains a development preview. The measured Windows-to-S25 results do not qualify every device or network.

A smaller-group direction

Longer-term development

Small groups are no longer only a plan. Voice calls, Tables holding several live screens, room discussions and consent-based file transfer all exist in preview, and that page states what each one still cannot do. These remain preview workflows: generated-audio group checks have passed, while audible calls and unrelated-network screen playback still need physical acceptance.

Reaction controls exist in the published desktop source; physical-device acceptance remains open. Message editing, deletion and unread counts remain unavailable. Recoverable devices and synchronized watching of a local file remain longer-term plans. Matching Windows, Android and Linux viewer downloads are available. Linux screen broadcasting is not included. Packages for macOS, iPhone and iPad, and Android screen broadcasting, remain unavailable.

Website comparison tables will stay “Not measured” until a public evidence index exists. Help shape the sequence through the issue tracker, without posting invitations or private screen content.
